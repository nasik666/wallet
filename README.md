# Кошелёк

Простой учёт личных денег: расходы и доходы в пару касаний, долги, вклады с процентами, статистика с графиками и экспортом. Работает прямо в браузере, без сервера и регистрации; рассчитан на iPhone (ориентир — 15 Pro Max), но открывается на любом устройстве.

**Открыть приложение:** <https://nasik666.github.io/wallet/>

## Что умеет

- **Быстрый ввод.** Кнопка «+» или значок категории на главном экране → сумма → «Добавить». Подпись («что, где, с кем») и дата — по желанию.
- **Категории.** Снеки, техника, кофе, обед, ужин и другие — для расходов; зарплата, подарок, подработка — для доходов. Свои категории добавляются в настройках или прямо при вводе.
- **Долги.** Две вкладки: «Я должен» и «Мне должны». Срок возврата, возврат частями, отметка о просрочке.
- **Вклады.** Сумма, ставка, срок, капитализация, пополнения и снятия. Проценты считаются сами, есть прогноз на месяц, год и конец срока.
- **Статистика.** Неделя, месяц, год или всё время: расходы по дням и категориям, сравнение с прошлым периодом, расходы и доходы по месяцам. Любой график переключается в таблицу.
- **Экспорт.** Отчёт за период и список операций в CSV (открываются в Excel, Numbers, Google Таблицах), полная копия в JSON и восстановление из неё.
- **Синхронизация.** Между устройствами — через ваш приватный GitHub Gist.
- **Офлайн.** После первого открытия работает без интернета; тёмная тема включается вместе с системной.

## Установка на iPhone

1. Откройте адрес приложения в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“».
3. Запускайте с иконки: приложение откроется на весь экран.

Данные, введённые во вкладке Safari и в установленном приложении, хранятся отдельно. Лучше сразу установить приложение на экран «Домой» и пользоваться им; перенести записи между ними можно через синхронизацию или «Экспорт» → «Восстановить из копии».

## Синхронизация между устройствами

1. Создайте на GitHub токен с единственным правом `gist`: <https://github.com/settings/tokens/new?scopes=gist&description=Koshelek>.
2. В приложении: шестерёнка → «Синхронизация между устройствами» → вставьте токен → «Подключить». Приложение создаст приватный gist с файлом `wallet-data.json`.
3. На втором устройстве вставьте тот же токен — gist найдётся сам, записи подтянутся.

Дальше всё происходит само: при каждом изменении и при открытии приложения. Если одну запись правили на двух устройствах, остаётся более поздняя правка; удалённые записи не возвращаются.

## Данные и приватность

- Записи хранятся в браузере на устройстве. В репозитории и на GitHub Pages ваших данных нет — там только код.
- С синхронизацией копия лежит в приватном gist вашего аккаунта. Приватный gist не виден в поиске и профиле, но доступен по прямой ссылке — не делитесь ею.
- Токен хранится только на устройстве. У него должно быть только право `gist`; отозвать его можно в настройках GitHub.
- Браузер может очистить данные сайта (например, при сбросе Safari). Включите синхронизацию или время от времени сохраняйте копию через «Экспорт».

## Как считаются проценты по вкладам

Проценты начисляются каждый день на текущий остаток: ставка / 365 (в високосный год — / 366). С капитализацией они раз в месяц, в день открытия, прибавляются к сумме вклада; без неё — копятся отдельно. Пополнение или снятие начинает учитываться со следующего дня. После окончания срока или закрытия вклад не растёт. Расчёт приблизительный: у банка могут быть свои правила округления и даты выплат.

## Публикация на GitHub Pages

Сборка не нужна — это обычные статические файлы.

1. Залейте содержимое папки в репозиторий на GitHub.
2. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Обновление — обычный `git push`. Установленное приложение подхватывает новую версию в фоне и показывает её со следующего запуска.

## Разработка

```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
node --test                   # тесты расчётов, слияния данных и синхронизации
```

| Файл | Назначение |
| --- | --- |
| `index.html`, `css/app.css` | Разметка и стили |
| `js/app.js` | Запуск, вкладки, главный экран |
| `js/txsheet.js`, `js/catform.js` | Ввод операции, категории |
| `js/stats.js`, `js/charts.js`, `js/export.js` | Статистика, графики, экспорт |
| `js/debts.js`, `js/deposits.js`, `js/settings.js` | Долги, вклады, настройки |
| `js/store.js`, `js/sync.js`, `js/calc.js` | Данные и их слияние, синхронизация с gist, расчёты |
| `sw.js`, `manifest.webmanifest`, `icons/` | Офлайн-режим и установка на экран «Домой» |
| `tests/` | Тесты и пример данных для ручной проверки |

На `localhost` офлайн-кэш выключен, чтобы правки были видны сразу; включить его для проверки можно адресом с `?sw`. Добавив новый файл приложения, допишите его в список `ASSETS` в `sw.js`.
